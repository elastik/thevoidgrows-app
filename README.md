# Void Core App

Open-source device control app for [The Void Grows](https://thevoidgrows.com) mushroom cultivation dome.

**Status:** In development

## Tech Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Capacitor (iOS/Android — coming soon)

## Development

```bash
npm install
npm run dev
```
